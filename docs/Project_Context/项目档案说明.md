# Hermes Recall 项目档案

## 项目介绍

Hermes Recall（回响）是 Hermes Agent 的本地智能备忘录与个人长期记忆基础。它保存用户过去的想法、计划和信息，并在需要时将这些信息重新带回当前上下文。

## Recall 定位

Recall 不是普通 Todo，也不是简单备忘录。它的核心是记录用户产生的回响，并随着时间理解事情的发展、变化和结束：记录过去、理解现在、在合适的时间重新唤起信息。

当前产品基线聚焦可靠的记录与提醒闭环；完整的语义记忆与事件演化能力仍在规划中。

## 当前版本

- 产品基线：Recall V1.0
- Skill 发布版本：1.0.3
- 数据 Schema：1.01

三类版本描述不同对象，不能互相替代。

## 长期目标

从信息记录工具成长为个人长期记忆与事件演化系统（Personal AI Memory System）。长期方向包括结构化记忆、关联与演化、主动回顾、可靠提醒和可扩展通知；这些方向尚未自动成为已实现功能。
