# V1.1 升级总览

> 状态：Completed
> 目标版本：V1.1（结构化记忆 + 回响式交互 + Reminder 生命周期 + 记录演化基础）
> 创建：2026-08-12

## 要解决的问题

1. 结构化记忆缺失：记录无法表达"这是什么记忆、重要程度、涉及什么、与什么相关"，单条记录只是孤立文本
2. 交互机械：高频操作（新增/查看/搜索/完成/归档/删除/提醒）缺少有"回响"辨识度的自然语言入口
3. 已确认缺陷与治理债：BUG-V11-001（Feishu 重复错误提示）、源码内部 v2 标识与产品版本不一致、时间无时区规范、validator 未覆盖完整 Contract
4. 提醒生命周期不可追踪：提醒发生 ≠ 任务完成，发送后状态无独立表达、投递失败无确认（FR-002 全量，已影响当前使用）
5. 记录无演化与关联基础：事情推进/变化/结束时无结构化追踪（FR-003 第一、二层）
6. 治理规范自身遗留：档案内互链归档处理、暂缓项去向两处规则缺失（随本升级更新规范 V1.4→V1.5）

## 本次目标

- 数据层：一次 Schema v2 升级，统一承载 memory 结构化字段 + timeline 时间线 + parent_id 父子关系 + 五状态模型 + FR-002 Reminder 生命周期实体
- 交互层：FEAT-V11-001 回响式自然语言交互（Intent 归一化，直白表达兼容）
- 展示层：时间线视图、父子关系展示、关联查询、Markdown View/search/stats 支持新字段
- 可靠性：BUG-V11-001 修复、版本口径统一、validator 全量覆盖、迁移有预检/备份/校验/恢复
- 规范层：治理规范 V1.4→V1.5（修两处遗留）

## 纳入范围（P1）

- V11-REQ-01 结构化记忆字段（memory_type/importance/entities/related_ids）
- V11-REQ-02 旧数据兼容与 Migration（预检/备份/校验/失败恢复）
- V11-REQ-03 原文与历史保护（content 不被改写、History 语义保持）
- V11-REQ-04 回响式自然语言交互（新增/查看/搜索/完成/归档/删除确认/Reminder 入口）
- V11-REQ-05 歧义与安全门（低置信度/多目标/删除/批量确认前零写入）
- V11-REQ-06 Reminder 语义边界（个人未来提醒 vs 系统轮询）
- V11-REQ-07 质量与版本治理（validator 全量、时区 ISO 8601、版本显示统一）
- V11-REQ-08 Gateway 缺陷修复（BUG-V11-001，V11-GW-001 回归）
- FR-002 全量：Reminder Lifecycle（五状态机 + Reminder Event/User Response/Completion State 实体；Reminder 状态与 Record 状态解耦；兼容不破坏现有提醒）
- FR-003 第一、二层：timeline 时间线、parent_id 父子回响、五状态模型、结构化字段、时间线视图/父子展示/关联查询、手动关联（字段按引擎输入契约一次设计到位，引擎将来直接消费历史数据）
- 工程治理：统一版本显示、时间带时区 ISO 8601、validator 全量覆盖、Migration 备份/dry-run/验证、History Contract 明确、规范 V1.5

## 明确不做（非目标）

- 附件/文件资源存储 → V1.2（评估参考飞书胶囊系统，recall_20260811_2a50da）
- 【每日回响】早+晚双轨 → 暂不做，版本未知
- FR-003 智能引擎（自动关联发现、主题聚合、主动建议）→ V1.3（数据结构已按引擎契约预留）
- 向量存储、embedding 管线、语义检索（V2.0 规划）
- SQLite（条件性方向，未触发复审信号）
- Weekly Review、自动修改关联记录
- 多平台通知、Provider/Identity/Routing 正式落地
- 产品化模式（Simple/Personal/Setup Wizard）、企微接入、远程存储载体
- 开放式诗歌/隐喻解析、用户自定义表达词典、大规模 Core 重写

## 关键约束

- 数据：JSON 主存储；V1.0 Record 必须可读；缺失新字段合法、读取不回写；迁移预检/备份/校验/失败恢复；一次 Schema v2 统一迁移（memory + timeline + Reminder 实体）
- 状态分层：Reminder 状态与 Record 任务状态解耦，互不隐式映射
- 安全：低置信度/多目标/删除/批量变更在确认前零写入；content 原文不因回响式反馈被改写；不自动修改记录
- 隐私：敏感实体不进日志与公开测试样本；真实数据只在本机验收、不进仓库
- 架构：不重写 Core、不建第二写入逻辑（回响表达归一化为 Intent 再走既有 Core/CLI）；不单独建回响持久化 Schema
- 版本：产品/Skill/Schema 版本独立管理并统一显示；BUG-V11-001 归属 Gateway 集成层、不改 Recall Schema
- 时间：所有时间字段强制带时区 ISO 8601
