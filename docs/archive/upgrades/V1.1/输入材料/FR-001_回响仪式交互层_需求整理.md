## 背景

当前 Recall 已具备记录和提醒能力，但交互体验接近普通备忘录。希望增加 Recall 独有的"回响"体验，同时保留普通使用方式。

## 目标：双交互模式

### Natural Mode（直白模式，保持现状）

- 记一下
- 提醒我
- 增加待办

### Echo Mode（回响模式，新增）

- 记录回响：保存长期信息
- 埋下一颗种子：保存想法
- 唤醒回响：创建提醒
- 寻找回响：查询历史
- 回响复盘：总结信息

## 原约束（2026-08-12 已决策处理）

FR-001 原约束：不修改 Recall Core、不修改 JSON Schema、Echo 只是交互层。

**该约束已标为历史 Input**：综合方案要求新增 memory 结构化字段（必须升级 Schema），2026-08-12 决策以《V1.1_升级需求与方案》为准（Schema v2 升级）；FR-001 仅保留"回响仪式交互层"意图，即交互层不建第二写入逻辑、归一化为 Intent 后走既有 Core/CLI。

## 与《V1.1_升级需求与方案》§4 的对应

| FR-001 回响命令 | 方案 Intent action | 行为要点 |
|---|---|---|
| 记录回响 | add | 保存正文，引导语不进 content |
